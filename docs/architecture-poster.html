HK Country Park Planner Search · Recommend · Plan

A pre-trip feasibility agent for Hong Kong trails. It does not look up scenery. It turns messy constraints into a checkable day plan — or a cited refusal.

COMP4431 domain chatbot
Single LLM · Skills · Tools · RAG
Not GPS · Not SOS · Not an encyclopedia
The idea

Existing apps already catalog and track. They do not argue with a bad plan.

Enjoy Hiking is a filter catalog. TrailWatch is on-trail GPS. HKSOS is rescue after failure. This agent sits before departure: hear incomplete constraints, fuse official data, and veto Instagram routes the data cannot support.

SEARCHSpoken constraints → structured trail query over a frozen official set.
RECOMMENDOne primary + one backup, with a why-not for the famous wrong trail.
PLANTransport, official duration vs sunset, GPX on a map canvas.
REFUSEClosures, T8 / rainstorm / thunderstorm on an exposed ridge, 5★ + beginner + half-day, finish after dark.
Why AI is the primary feature
Users do not speak AFCD star ratings. They say “half day, sea view, rained last night”.
The model negotiates constraints and explains tradeoffs. Numbers never come from the model — only from tools.
Question cards pause the loop when a decision is still missing (single / multi / free text).
Architecture — one LLM, a harness, not a 2010s dialogue engine
